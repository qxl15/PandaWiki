# 通达OA「接口用户信息」页面填写指南（对应你截图）

适用：通达OA 12.9，且你当前要求“仅读取权限，不写入OA”。

## 1. 每个字段怎么填

- **用户名**：填一个专用接口账号，例如 `oa_att_readonly`。
- **密码 / 确认密码**：设置高强度密码（建议 16 位以上，字母+数字+符号）。
- **用户状态**：选择 `启用`。
- **模块权限**：
  - ✅ 勾选 `互联互通访问接口`
  - ✅ 勾选 `数据交换访问接口`
  - ❌ 不勾选任何写入/审批类无关权限（你是只读场景）
  - `工作流`建议不勾选（除非你后续要读工作流数据）
  - `提醒`可不勾选（本工具不依赖该项）
- **备注**：建议写 `考勤只读接口账号（供 oa_attendance_tool 服务端使用）`。
- **内容后缀（仅事务提醒有效）**：可留空。

## 2. 创建后要填到哪里

只填在服务器端 `.env`：

- `TD_OA_API_USERNAME=<你刚创建的用户名>`
- `TD_OA_API_PASSWORD=<你刚设置的密码>`

客户端不填、也不保存这些OA凭据。

## 3. 验证是否配置成功

1. 启动服务端。
2. 客户端点“测试连通”。
3. 客户端登录成功后，执行一次手动同步。
4. 能查到人员/打卡数据即表示接口账号权限可用。
